# User-Data-Entry-System-with-CRUD-Functionality

# Overview
The User Data Entry System is a simple application that provides CRUD (Create, Read, Update, Delete) functionality for managing user data. This application is built to help developers understand basic CRUD operations and serves as a foundation for building more complex applications.

## Features
- **Create**: Add new user records.
- **Read**: View a list of all user records.
- **Update**: Edit details of existing user records.
- **Delete**: Remove user records from the system.

## Technology Stack
- **Frontend**: React Js
- **Backend**: Node Js (Express Js)
- **Database**: MongoDB
